# 물건 계산하기 게임

특수학교 학생이 여러 가게에서 물건을 고르고, 가격을 더하고, 현금·카드로 결제하고, 영수증을 확인하는 연습 게임입니다.

## 게임하기

- [GitHub Pages에서 열기](https://zxc3285123-web.github.io/shopping-practice-game/)
- [기존 공유 주소에서 열기](https://shopping-practice-game.zxc3285.chatgpt.site/)

## 활동

- **물건 담기:** 목록을 보고 필요한 물건만 고릅니다.
- **연습하기:** 물건 담기부터 계산·결제·영수증 확인까지 진행합니다.
- **미션하기:** 가게와 구매 물건을 확인하고 미션을 수행합니다.

난이도를 조절할 수 있습니다. 음성 안내를 들을 수 있으며, 연습용 결제만 이루어집니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 이미지와 음성 파일은 같은 저장소의 `food/`, `items/`, `audio/` 폴더에 있어야 합니다.
